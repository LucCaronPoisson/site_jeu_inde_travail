# 🎮 Indie Game Studio — Site officiel

## Présentation

Site vitrine d'un studio indépendant de développement de jeux vidéo.

Ce site a pour objectif de présenter le studio, son identité, ses projets vidéoludiques ainsi que ses coordonnées.

L'interface adopte une direction artistique moderne et immersive, inspirée de l'univers du jeu vidéo indépendant.

## Technologies utilisées

Le projet est développé uniquement avec les technologies natives du web :

- **HTML5** : structure et contenu du site.
- **CSS3** : mise en page, animations et responsive design.
- **JavaScript Vanilla** : interactions et fonctionnalités dynamiques.

Aucun framework ou bibliothèque externe n'est utilisé.

## Fonctionnalités

- Présentation du studio.
- Présentation des jeux développés.
- Galerie visuelle des projets.
- Section actualités.
- Coordonnées et réseaux sociaux.
- Navigation entre les différentes sections.
- Animations et interactions.
- Interface responsive (ordinateur, tablette et mobile).
- Formulaire de contact
- Recherche de jeu par style

## Installation et lancement

Aucune installation ou compilation n'est nécessaire.

1. Télécharger ou récupérer le projet.
2. Ouvrir le dossier du projet.
3. Ouvrir le fichier `index.html` dans un navigateur web.

Le site fonctionne entièrement en local.

## Personnalisation

Les éléments suivants peuvent être personnalisés :

- Logo et identité visuelle du studio.
- Couleurs et typographies.
- Présentation de l'équipe.
- Images et descriptions des jeux.
- Coordonnées et réseaux sociaux.
- Actualités et annonces.
